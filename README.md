# Gandalf Security System

A multi-level security system where users must find passwords to advance through levels. Each level is protected by Gandalf, who will try to prevent users from discovering the passwords.

## Features

- 7 levels of security
- Interactive chat interface
- Gandalf-themed responses
- Progressive difficulty
- Modern, responsive design

## How to Play

1. Visit the website
2. Try to discover the password for each level
3. Enter the password to advance to the next level
4. Each level gets progressively more challenging

## Technical Details

This project uses:
- HTML5
- CSS3
- JavaScript
- Flask (Backend)
- DeepSeek API for AI responses

## Setup

1. Clone the repository
2. Install the required Python packages:
   ```
   pip install flask flask-cors requests
   ```
3. Run the server:
   ```
   python server.py
   ```
4. Open `index.html` in your browser
